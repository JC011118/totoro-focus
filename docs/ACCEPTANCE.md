Path shorthand:
- `core/<file>::<test>` means `crates/focus-core/tests/<file>.rs`. Run one with `cargo test -p focus-core --test <file> <test>`. The pack tests sit inside `mod packs`, so their names start with `packs::`.
- `shell/<mod>::tests::<test>` means `src-tauri/src/<mod>.rs`. Run one with `cargo test -p focus-companion <mod>::tests::<test>`.
- `vt:<file> › "<name>"` is a Vitest test. Run one with `npx vitest run <file> -t "<name>"`.

Status legend:
- **automated**: tests cover the whole check.
- **partial**: the logic is tested, but the macOS/OS part is not.
- **manual**: the check can only be verified on a Mac.
- **gap**: the check is not implemented or not done.

Every "Remaining manual" entry is **pending**. Nothing here has been run on macOS.
